E-Shop Pro

Full-Stack E-commerce Application

Built with React (Next.js), Python (FastAPI), and SQLite.

Frontend

Located in the frontend/ directory.

A responsive React application built with Next.js and Tailwind CSS.

Backend

Located in the backend/ directory.

A robust REST API built with Python FastAPI and SQLAlchemy.

Note for GitHub Pages: This project contains a Python backend which cannot run on static hosting services like GitHub Pages.

To run this project, you must set it up locally:
1. Start the backend: uvicorn backend.main:app
2. Start the frontend: cd frontend && npm run dev
